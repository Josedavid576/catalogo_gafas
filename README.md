# Catálogo de Gafas — SAVIG Optical

Página web estática creada a partir del PDF de monturas de caballero proporcionado.

## Cómo abrir
1. Abre `index.html` en el navegador.
2. No requiere Node, servidor ni instalación.
3. Puedes buscar por modelo/código y abrir cada montura en una vista ampliada.

## Estructura
- `index.html`: estructura y catálogo.
- `styles.css`: diseño responsive.
- `assets/`: imágenes extraídas del PDF y optimizadas para web.

Los nombres `Montura 01`–`Montura 80` y códigos `MG-01`–`MG-80` se usan como identificadores de catálogo porque el PDF no contiene texto extraíble legible con los nombres/códigos de cada modelo.
